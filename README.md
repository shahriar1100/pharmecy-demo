# আপনার ফার্মেসি

একটি polished, mobile-first Bengali pharmacy and personal-care landing page। প্রকল্পটি React, Vite, Tailwind CSS, Motion এবং Lucide React দিয়ে তৈরি।

## Features

- Responsive Bengali storefront
- Search and category filtering
- Accessible product details modal
- Medicine-safe inquiry-only flow
- Cart drawer with localStorage persistence
- FAQ accordion and refined animations
- Store details and product catalog in editable configuration files

## Local development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Configuration

- Store details: `src/config/store.js`
- Product catalog: `src/data/products.js`

Unknown prices and unconfigured contact information are intentionally shown as unavailable rather than being fabricated.
